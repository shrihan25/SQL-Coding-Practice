# SQL Practice

This repository contains the SQL questions I have been practicing for improving my SQL skills and preparing for interviews.

I have divided the questions into different sets based on difficulty and importance.

* SQL Basic to Medium – 100 Questions
* SQL Medium to Hard – 150 Questions
* SQL Hard – 150 Questions
* SQL Most Important – 100 Questions

The questions cover topics such as filtering, sorting, aggregation, joins, subqueries, CTEs, window functions, date functions, ranking, and analytical queries. The harder sets also include topics like recursive CTEs, cohort analysis, streaks, data quality, anomaly detection, and more complex business queries.
All the queries in these practice sets use MySQL 8.0.

I made this repository mainly for practice and revision. I try to solve the questions on my own first and then check the query to understand where I can improve.

I will keep updating this repository as I continue practicing SQL.
